# 📰 Modeling User Perspectives in Rumour Dissemination

This project focuses on **stance classification** in social media platforms like Twitter. It categorizes tweets in rumour threads into four types: **Support, Deny, Query, and Comment (SDQC)**. This helps understand how users react to rumours and supports misinformation analysis and moderation.

---

##  Problem Statement

Social media is a powerful but vulnerable platform where false information spreads rapidly. By modeling user stances, this project helps track public perception, identify misinformation patterns, and support accurate content moderation.

---

##  Objectives

- Categorize tweet reactions into SDQC stance types.
- Use NLP-based techniques and word embeddings.
- Train ML models to analyze and classify rumour responses.
- Support multilingual analysis using IndicTrans2.

---

## 📁 Dataset

- Sourced from **SemEval 2017 Task 8**
- Covers major real-world events like:
  - Charlie Hebdo attack
  - Ferguson protests
  - Germanwings plane crash
